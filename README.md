# Bank System Database & ERD Architecture


## Academic Context
This project was developed as a practical coursework assignment for the **Database Systems Course**, demonstrating full Database Lifecycle Implementation from ER Diagram design to SQL script generation.

 ## Overview
 This project presents a comprehensive design and implementation for a **Relational Banking Database System**. It covers the entire lifecycle from conceptual domain analysis (ERD) to schema mapping and execution of SQL table scripts.


## Features & Capabilities
* **Customer Management:** Tracks detailed profile information and contact data. 
*  **Account Operations:** Supports checking and savings accounts with automated transaction logic.
*  **Relational Integrity:** Implements strict primary/foreign keys and constraint validation.  


## Project Structure 
* `schema.sql` — DDL scripts for table creation and constraints.
*  `Bank_ERD_Documentation.pdf` —
     Conceptual and relational schema representations.
